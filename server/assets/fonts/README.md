# Report fonts

Unmodified Noto Sans Regular and Bold from
https://github.com/notofonts/noto-fonts/tree/ffebf8c1ee449e544955a7e813c54f9b73848eac/hinted/ttf/NotoSans

These fonts retain the SIL Open Font License in OFL.txt. They are embedded in
reports so rendering does not depend on fonts installed on the server or reader.
Validation covers Latin (including German), Greek, Cyrillic and engineering units;
this is not a claim of coverage for every Unicode script.
