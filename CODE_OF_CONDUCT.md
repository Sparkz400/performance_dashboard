# Community conduct

Be respectful, constructive and patient. Discuss technical decisions with
evidence. Welcome different experience levels and backgrounds.

Harassment, discrimination, threats, sexualized content, personal attacks and
publication of private information are not acceptable. Do not post real plant
credentials, identifying customer data or sensitive machine exports.

Maintainers may edit or remove contributions and restrict participation to keep
the project welcoming and safe. Report concerns to the repository owner through
a private channel listed on their GitHub profile. If no private channel is
available, request one without publishing the incident's private details.

These expectations apply in project issues, pull requests, discussions and other
project-managed spaces. Enforcement should be proportionate and explain the
behavior being addressed, while respecting privacy.
