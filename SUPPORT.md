# Support

Use [Discussions](https://github.com/Sparkz400/performance_dashboard/discussions)
for setup questions and early ideas. Use the issue templates for reproducible
bugs, documentation errors and concrete feature requests.

Include the commit, operating system, Node.js version and sanitized logs. For
machine connectivity, specify the protocol and server software or simulator.
Remove credentials, private addresses and customer data before sharing.

This community project has no support SLA. Security reports belong in
[private advisories](SECURITY.md), not public issues.

The [maintainer handbook](MAINTAINERS.md) names current responsibilities and explains
triage, escalation and handover. A contributor issue or maintainer nomination does
not create a support commitment.
