# Figtree

Unmodified variable WOFF2 fonts by Erik Kennedy, bundled for local and offline
installations under the [SIL Open Font License 1.1](OFL.txt).

Source: https://github.com/erikdkennedy/figtree/tree/032dfa7fe219ef3a02890d6d3add84eacc9aebfe/fonts/webfonts

- `Figtree[wght].woff2` is saved as `Figtree-Variable.woff2`.
- `Figtree-Italic[wght].woff2` is saved as `Figtree-Italic-Variable.woff2`.

The UI uses weights 400–700, tabular numerals, and the full supplied character
set. Technical identifiers and raw diagnostics keep their monospace styles.
No font CDN or runtime download from a third party is required.
